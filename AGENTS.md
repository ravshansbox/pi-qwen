# AGENTS

## Communication

- Use British English spelling and terminology in all responses to the user and all user-facing text.
- When the user asks a question, answer it directly; do not take actions unless requested.

## Checks

- Run `npm run check` before committing.

## Version control

- Use Conventional Commits format for all commit messages (e.g., `feat: ...`, `fix: ...`, `chore: ...`).
- Create atomic commits: each commit should contain a single logical change.
